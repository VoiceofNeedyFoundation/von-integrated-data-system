# Voice of Needy Integrated Data System

This repository is the shared engineering workspace for Voice of Needy Foundation's Integrated Data System.

## Current scope

The project is in evidence-led discovery and business data-model review. Current work is limited to GitHub documentation, source inventory, data profiling and preparation for review checkpoints. No Supabase or Vercel change is authorised in the current scope.

Do not commit raw participant data, credentials, exports, screenshots containing personal information or local working files.
