# Voice of Needy Integrated Data System

This repository is the shared engineering workspace for Voice of Needy Foundation's Integrated Data System.

## Current scope

The project is in evidence-led discovery and professional data-architecture review. Current work is limited to GitHub documentation, source inventory, data profiling, layered architecture, relational modelling and dashboard-design preparation. No Supabase or Vercel change is authorised in the current scope.

Do not commit raw participant data, credentials, exports, screenshots containing personal information or local working files.
